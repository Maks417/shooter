[Visual quality milestones VD0–VD9](../design-milestones.md) define the owner's Battlefield V / Bodycam / Warface goal within M8–M11. Start with art direction and a representative art slice, then execute component and final-review gates. Execution follows the [visual roadmap](../visual-roadmap.md); all visual exits are Pending.

Each folder contains its milestone entry, validation/acceptance and handoff record; M8–M11 also keep their implementation, contracts/integration and agent assignment pages. The pre-work planning pages of closed M0–M7 are in the [archive](../archive/index.md). Requirements and feature specifications live once in the docs root, reached through relative links from each milestone. Code and accepted artifacts from prerequisite milestones are still required to execute.

## Maintenance

Root documents are authoritative shared specifications. Update them in place and rerun the root verifier with intentional manifest refresh. Milestone plans link to these shared files; do not duplicate them or use local plans to relax shared requirements. Each pack index links all local implementation documents and the shared documentation index. Test results are recorded only in handoffs, with exact evidence.
