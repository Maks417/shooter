# Compiler artifact format v1

P02 initial format freeze, 2026-11-12. This additive compiler format leaves frozen C0 DTOs and specification-v1.1 fixtures unchanged. No shipping content existed in P01. The compiler owner is the integrator. All five codecs passed their independent golden and negative checks before generator integration; the numeric collision diagnostic has actual cold/warm/forced/dry-run editor evidence. Full M1 content and hardware gates remain pending. See [generation](generation.md), [deterministic identities](deterministic-format.md) and [M1 handoff](milestones/m1-procedural-feasibility/handoff.md).

## Envelope and primitive encoding

Every production artifact uses magic ASCII SGAF, uint32 version=1, uint32 ContentKind, uint32 compression=0, uint32 body byte length, SHA256(body) 32 raw bytes, generator fingerprint 32 raw bytes, toolchain hash 32 raw bytes, then body. Header size is 116 bytes. File length equals header plus body, with no trailing bytes. Maximum entire file is 64 MiB. Integers and IEEE float32 are little endian, finite floats only. Strings are uint32 byte length plus printable ASCII bytes, at most 4096 bytes. No native struct dumps, runtime type names or compression. Artifact manifest hash covers the whole file. The generator fingerprint is SHA256 of LP(generatorId)+LP(generatorVersion). Decoder verifies expected kind/fingerprints and body hash before typed decode.

## Typed bodies

- Mesh: uint32 vertex/index/submesh counts, uint32 skin flag (0/1); vertex records in order position float3, normal float3, tangent float4, UV float2, plus joints uint16x4 and weights float4 when skinned; uint32 indices; submesh records firstIndex/indexCount uint32, materialSlot uint16. Counts bounded by C0 and remaining bytes before allocation. Index ranges, finite vectors, submesh coverage, unit normals/tangents, weights and nondegenerate triangles validate before acceptance.
- Skeleton: uint32 joint count (1..256), then id/parentId uint16, local bind position float3, local bind quaternion float4, min/max angles float3 each. Parent 65535 is root. Exactly one root, unique IDs, no missing parents/cycles; no semantic soldier joint registry is invented here.
- Material: width/height uint16, LP(channelFormat), uint32 mip count, each mip as uint32 byte count plus bytes. Formats rgba8-linear / rgba8-srgb only. Complete mip chain to 1x1; each level has width*height*4 bytes. Albedo uses sRGB RGB, A opacity; normal uses linear tangent XYZ encoded to 0..255, A=255; mask uses linear R metallic/G occlusion/B roughness/A=255. Plane semantic is its variant name, not a new ContentKind.
- Collision: uint32 capsule/box/height-grid counts; capsules bottom/top sphere centers float3, radius float32, surfaceTag uint16; boxes center/size float3, rotation float4, surfaceTag uint16; grids origin float3, width/depth uint16, spacing float32, surfaceTag uint16, then width*depth float32 heights. C0 validation applies and all count products check before allocation.
- Navigation: LP(adapter format), uint32 adapter version, settings hash 32 bytes, uint32 blob bytes followed by opaque validated adapter data. Decode validates envelope/size only; actual navigation adapter acceptance remains M3.

## Manifest and migration boundary

Production uses a separate shooter.content.manifest.v1 schema; the C0 manifest is explicitly a nonshipping three-byte diagnostic and remains unchanged. Production JSON is bounded canonical v1 with deterministic inputs, bounds/counts, artifacts and numeric-source provenance. Build timings and worker identity stay in external reports. Exact production manifest fields and tested limitations are recorded with P02 implementation. There is no pre-existing shipping cache to migrate; unsupported envelope/schema versions fail, and old diagnostic caches are not reinterpreted. Future layout or generator algorithm changes require a new version, independent fixtures and reviewed migration policy.

## Production schema and validation details

The [production manifest schema](content-schemas/manifest.schema.json) and [collision recipe schema](content-schemas/box-collision.schema.json) are new schemas, outside the immutable C0 fixture catalog. Manifest fields are exactly manifestSchema, contentId, sourceHash, recipeId, generatorId, generatorVersion, seed, toolchainHash, buildPlatform, visualProfile, dependencies, artifacts, bounds, counts, materialLayerIds, provenance, validationSummary. Unknown fields reject. Dependencies and material layer IDs are sorted unique, at most 256. Artifacts sort by kind enum then variant and use `<kind>-<variant>.bin`, with variants restricted to lowercase ASCII letters/digits/underscore/hyphen (1..64). Manifest hashes cover complete SGAF files; compressed/uncompressed sizes are equal and include the header. Bounds are conservative integer millimeter min/max triples; integer inversion is checked before float conversion. Counts record vertices, triangles, submeshes and bones and are verified against decoded payloads. Provenance is sourceKind=numeric-recipes, policy=procedural-v1, with sourceHash and generator/toolchain identities in the root. Validation summary is validated-v1; runtime never trusts this label instead of decoding.

Mesh normal/tangent length, normal-tangent orthogonality and tangent handedness tolerances are 1e-4; triangle cross-product squared must exceed 1e-20 square meters squared (m^4). Submesh ranges cover every triangle exactly once. Bounds containment permits 0.1 mm arithmetic tolerance. The independent diagnostic triangle body hash is `5fadfc0750ffea4a40dfc5cbaadf455f95fead77e5d61907d7bb125492b73232`; its 298-byte SGAF file hash is `4ba40a98b6167bfc5bdeb040c26134b2368cca013e478e58fc8bf38e154d8f22` for generator hash all zero/toolchain hash all 0x11. The tiny test recipe is numeric diagnostic data, never a manually authored game mesh. `Tools/Generation.Tests/CodecFixtures/generate_vectors.py` independently produces its bytes with Python struct packing.

Collision/navigation content uses profile gameplay and cannot mix visual artifacts into the same request. Pure material planes use a visual profile. Gameplay IDs therefore remain identical across Low/Balanced/High editor requests. Generic IContentStore kind lookup rejects ambiguity when several variants exist; FileContentStore.AcquireVariantAsync explicitly selects a named variant. Leases expose verified complete SGAF file bytes; adapters decode the envelope before typed use. Byte release is safe on any thread; future Unity resource installation/release still requires the main thread.

The compiler accepts the two explicitly validated box source schemas. Only collision.box 1.0.0 / shooter.recipe.box-collision.v1 has a real generator in P02, supports bevelMm=0, has no dependencies and emits one axis-aligned box. General DAG behavior is tested with test-only generators. Geometry.box validates the old fixture but has no shipping P02 generator. Navigation decode validates structure only; the M3 navigation adapter must validate its blob. A future feature generator requires its own registered schema and version; no arbitrary runtime code execution or fallback is available.

## Publication and local cache assumptions

The editor/tools compiler writes durable files into its unique sibling staging directory, rechecks lengths and hashes, then atomically renames on the same volume. The index for the last completely successful requested set switches with atomic replacement after all content verifies. Earlier complete dependency outputs may remain if a later node cancels/fails; no incomplete content becomes visible and the prior index remains. OS exclusive handles provide cross-process per-key locks; process termination releases ownership, persistent empty lock files do not imply ownership and are never deleted as stale locks. Timeouts/cancellation reject busy requests. Same-key/different-byte output fails; corrupt existing content is retained for explicit repair, never overwritten or deleted. Capacity defaults to 8 GiB with refusal instead of automatic eviction; LRU/purge and crash-orphan staging reclamation are not implemented in this skeleton.

Content readers check existing path ancestors for reparse points and escaping/ambiguous paths, deny concurrent ordinary writes while reading, and check size before allocation. These are cooperative local filesystem checks, not a claim of race-proof isolation against an attacker who can replace cache ancestors between checks. Runtime residency is bounded to at most 256 MiB verified file bytes, with at most 64 pending loads, 256 waiters and bounded active leases. Transient decode/copy working memory is additional and bounded by file/content limits; reference-machine peak compilation/load memory remains unmeasured. No Unity objects or content compilation occur in FileContentStore. Future shipping composition must validate trusted build/content manifests before use; this diagnostic is not installed into gameplay.
